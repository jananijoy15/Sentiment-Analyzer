😊 Sentiment Analyzer

Sentiment Analyzer is a simple web-based Text Analysis application that analyzes user-entered text and identifies whether the sentiment is Positive, Negative, or Neutral.

Live Application Link 
https://jananijoy15.github.io/Sentiment-Analyzer/

✨ Features

- 📝 Analyze user-entered text
- 😊 Detect positive sentiment
- 😞 Detect negative sentiment
- 😐 Detect neutral sentiment
- 📊 Display sentiment score
- 🔍 Show detected sentiment words
- 📱 Mobile-friendly responsive interface
- ⚡ Fast analysis using JavaScript

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter a sentence or paragraph.
3. Click the Analyze Sentiment button.
4. The application analyzes the text.
5. The sentiment and score are displayed.

💡 Example

Input:

I really enjoyed this wonderful experience.

Output:

Sentiment: Positive 😊

📊 Sentiment Categories

Sentiment| Description
😊 Positive| Shows positive feelings or opinions
😞 Negative| Shows negative feelings or opinions
😐 Neutral| Shows no strong positive or negative feeling
